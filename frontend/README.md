# Craftspace — Craft Workshop Frontend

Responsive React + Vite + Bootstrap UI for the Craft Workshop Spring Boot CRUD backend.

## Features
- Responsive navbar and dashboard summary cards
- Add workshops (ID is generated by the backend; the form has no ID field)
- Display all, search/filter, and find a record by ID
- Update and delete records
- Validation for workshop name, material cost, and participant count
- Loading indicators and success/error messages

## Run locally
Install Node.js 18+, ensure the Spring Boot backend is running, then:

```bash
npm install
```

Copy `.env.example` to `.env` if needed and set `VITE_API_BASE_URL=http://localhost:8080`, then run:

```bash
npm run dev
```

Vite normally opens at `http://localhost:5173`.

## Expected backend endpoints
| Operation | Method | Path |
|---|---|---|
| Add | POST | `/Add` |
| Display all | GET | `/displayAll` |
| Display by ID | GET | `/displayById/{id}` |
| Update | PUT | `/update/{id}` |
| Delete | DELETE | `/delete/{id}` |

Request fields: `className`, `materialCost`, `participantCount`, `completed`. Display responses should include `id`.

## CORS
Allow the Vite origin in your Spring Boot controller or CORS configuration, e.g. `@CrossOrigin(origins = "http://localhost:5173")`.

For Docker, configure the browser-reachable backend URL using `VITE_API_BASE_URL` and rebuild the frontend image after changing it. `localhost` in browser JavaScript refers to the user's computer, not automatically to a backend container.

Build production assets with `npm run build` (output: `dist/`).
